# AI-logistics-quote-reader
This project extracts structured logistics pricing data from **shipping line PDF quotes** using **Python + LLMs (Gemini / Claude)**.


⚠️ **No data files are included in this repository.**
Users must provide their **own PDF quote files**.


## 🚀 Features

- Extracts multi-page PDF quote data
- Handles multi-line tables
- Ignores overweight / weight-based charges
- Cleans origin & destination fields
- Outputs strict, validated JSON
- Designed for **POC / demo / internal tools**
